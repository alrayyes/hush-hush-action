# Hush Hush Action

[![licence](https://img.shields.io/badge/licence-GPL--3.0-blue)](LICENSE)

A composite GitHub/Forgejo Actions action that fetches and decrypts one
secret from a self-hosted [Hush Hush](https://github.com/alrayyes/Hush-Hush)
secrets object store, for use in deployment pipelines.

**Status: in development.** The action itself isn't implemented yet — see
[#1](https://github.com/alrayyes/hush-hush-action/issues/1) for the design
and progress. This README will describe real usage once it lands.
